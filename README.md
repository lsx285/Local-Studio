# Local Studio

Native Swift 6 iPhone client for local ComfyUI chat, image generation and editing. The composer selects installed models and enhances text prompts with Qwen3-VL 4B Heretic NVFP4, including attached images. Responses and prompt enhancement stream from the PC. Settings offers resolution in 0.1 MP steps and aspect ratios with proportionate icons. Generated images retain their filename, prompt, seed, sampling settings and model files in the Photos-style info view. Retry uses the response’s original model; editing a user prompt uses the current selection.

Start `run_nvidia_gpu.bat` in the configured ComfyUI portable installation. The Local Studio extension advertises `_localstudio._tcp` over Bonjour and serves the model catalog and builds and queues native workflows in one request. The iPhone discovers the PC on the same local network; allow Local Network access when prompted. The composer stays disabled while disconnected. Discovery retries every five seconds until connected and resumes after a request fails due to a lost connection. No address configuration is needed. TCP 8188 and multicast DNS must be reachable on the private network.

Normal conversations persist on the iPhone; temporary conversations stay in memory. Original attachments are uploaded without client-side resizing. The image workflows use their published sampling presets, including Qwen Turbo's fixed eight-step sigmas and Fibo Edit Turbo's four-step CFG 1 preset. MOSS SFT is offered for generation; its separate editing LoRA is not installed.

Compilation happens only in GitHub Actions using Xcode 27.2, iOS 27.2 and Swift 6, targeting iOS 27 or newer. Pushes upload an unsigned `LocalStudio.ipa`. Device signing and installation remain external. The workflow contains no simulator or test steps.
